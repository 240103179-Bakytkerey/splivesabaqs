# JUZ40 LIVE — сайт + кеңейтім (1.2.0, сынақ нұсқасы)

JUZ40 әдіскерлеріне арналған LIVE сабақтарының жоспарлаушысы. 1.0.5 кеңейтімінің ішіндегі жоспарлаушы енді жеке **сайт** болды, ал juz40-edu.kz бетіндегі әрекеттерді бұрынғыдай **Chrome кеңейтімі** орындайды.

```
Сайт (Vercel / Netlify)                Chrome кеңейтімі                     juz40-edu.kz
кесте, тексеру, баптаулар,   ──►  bridge.js ──► background.js ──►  content.js + ui.js
курстар, сілтемелер          ◄──  (postMessage)   (port)       ◄──  (1.0.5-тегі код)
деректер: localStorage
```

- **Сайт** — кесте енгізу (қолмен және мәтіннен), сүзгілер, келесі аптаға көшіру, тексеру нәтижесі, таңдап түзету, орындау барысы, сілтемелер мәтіні, баптаулар, курс каталогы, JSON резервтік көшірме, кеңейтімді орнату нұсқаулығы. Деректер әр адамның өз браузерінде сақталады, логин жоқ.
- **Кеңейтім** — өз жоспарлаушы беті жоқ. Тек сайттың командасын қабылдап, JUZ40 жеке терезесінде сабақты іздейді, Meet құрады, сақтайды, жариялайды және қайта ашып тексереді.

## 1.2.0: juz40-edu.kz API режимі (сынақ)

Сайттың жоғарғы панелінде жаңа таңдау бар: **Бет арқылы** (бұрынғы тәсіл) немесе **API арқылы (сынақ)**.

API режимінде кеңейтім жеке терезе ашпайды және бетті баспайды. Сол қадамдар (сабақты іздеу, тақырып/сабақ құру, Meet құру, бар Meet-ке байланыстыру, сақтау, жариялау, қайта оқып тексеру) `https://api.juz40-edu.kz` сұрауларымен орындалады — juz40-edu.kz сайтының өзі жіберетін сұраулармен бірдей. Жоспарлау логикасы (`model.js`, `runner.js`) өзгертілмеді: API бөлігі бет режиміндегі әрекеттердің атауы мен нәтижесін қайталайды.

```
runner.js ─► connector.js ─► bridge.js ─► background.js ─► juzapi.js ─► api.juz40-edu.kz
                                             (api)          Bearer токен — таңдалған JUZ40 бетінің localStorage-ынан
```

| Қадам | API сұрауы |
|---|---|
| Тақырыпты табу / құру | `GET /v2/themes?courseId&month&week`, `POST /v1/themes` |
| Сабақты табу / құру | `GET /v2/headteacher/themes/{id}/lessons`, `POST /v1/lessons` (`PRACTICAL`) |
| Сабақты оқу | `GET /v1/lessons/{id}` (+ топтар, ұйымдастырушы email-дері, тапсырма тегтері) |
| Meet құру / түзету | `POST /v1/lessons/practics/meetings`, `PUT /v1/lessons/practics/meetings/{id}` |
| Бар Meet-ке байланыстыру | `POST /v1/lessons/practics/meetings/{id}/links`, `PATCH /v1/lessons/practics/meeting-links/{id}` |
| Атауы, нұсқаулық, балл, тег, рейтинг | `PUT /v1/lessons/practics/{id}` |
| Жариялау / жариялауды өшіру | `PATCH /v1/lessons/{id}/publish?publish=true\|false` |

Қауіпсіздік ережелері бет режиміндегідей:

- Токен тек `api.juz40-edu.kz`-ке жіберіледі, сайтқа (Vercel) берілмейді. Сайт өзі API-ге қосылмайды (CSP `connect-src 'self'` өзгермеді).
- «Тексеру» және «Бетті тексеру» тек `GET` жібереді.
- Сервер нақты 4xx қайтарса — қадам «қауіпсіз» тоқтайды. Жауап келмесе, уақыт бітсе немесе 5xx болса — сабақ **«Нәтиже белгісіз»** болып қалады, Meet қайта құрылмайды.
- Уақыт сайттың өз форматымен жіберіледі: жергілікті күн мен уақыт → ISO UTC (`…Z`); сервердің белдеусіз жауабы UTC ретінде оқылады.
- Курс топтарын сайт тек **бас мұғалім (headTeacher)** рөлінде береді, сондықтан API режимі сол аккаунтпен жұмыс істейді.

Эндпоинттер мен сұрау денелері juz40-edu.kz сайтының ашық JS бумасынан алынды (04.11.2026). Нақты аккаунтта әлі сыналған жоқ — төмендегі «Әлі тексерілмегені» бөлімін қараңыз.

## Не өзгерді (1.0.5 → 1.1.0)

- Жоспарлау логикасы (`model.js`, `runner.js`, `courses.js`) және сайтпен жұмыс істейтін бөлік (`content.js`, `ui.js`) **өзгертілмеді** — 1.0.5-те тексерілген әрекеттер сол күйі қалды.
- 1.0.5 жоспарлаушысындағы `adapter` (терезе ашу, бетті жүктеу, скриптті енгізу, уақыт лимиттері) кеңейтімнің `background.js` файлына көшті.
- Жаңа `bridge.js` сайт беттерінде ғана іске қосылады. Кеңейтім басқа сайттардан команда қабылдамайды: `manifest.json` → `content_scripts.matches` және `background.js` ішіндегі шығу тегі тексерісі.
- Жауап келмеген команда «қауіпсіз» деп саналмайды: байланыс үзілсе немесе уақыт бітсе, сабақ бұрынғыдай «Нәтиже белгісіз» болып қалады, Meet соқыр түрде қайта құрылмайды.
- Кезек жүріп жатқанда кеңейтімнің фондық бөлігі ұйықтап қалмас үшін әр 20 секунд сайын сигнал жіберіледі.
- Сайтта жаңалары: «Таңдалғанды жою», курсты жою, жұмыс терезесін көрсету, тексеру қорытындысы, қараңғы режим, телефонға бейімделу, бірнеше қойынды арасында деректерді жаңарту.
- Кеңейтім белгішесін басқанда сайт ашылады.

1.0.5 нұсқасының толық тарихы: [docs/extension-1.0.5-README.md](docs/extension-1.0.5-README.md).

## Vercel-ге жариялау

1. [vercel.com](https://vercel.com) → **Add New… → Project** → осы GitHub репозиторийін таңдаңыз.
2. Баптауларды өзгертудің қажеті жоқ: `vercel.json` ішінде build командасы (`node scripts/build.mjs`) мен `dist` қалтасы көрсетілген.
3. **Deploy**. Build кезінде `VERCEL_PROJECT_PRODUCTION_URL` бойынша кеңейтім архиві сайттың өз доменіне бапталады — сайттан жүктелген кеңейтім сол сайтпен бірден жұмыс істейді.

Netlify: **Add new site → Import from Git** — `netlify.toml` бәрін өзі көрсетеді (домен `URL` айнымалысынан алынады).

Басқа домен қолмен берілуі мүмкін: `SITE_URL=https://example.kz node scripts/build.mjs`.

> Репозиторийдегі `extension/` қалтасы әдепкі бойынша `https://splivesabaqs.vercel.app` және `localhost`-пен жұмыс істейді. Сайт басқа доменде болса, кеңейтімді сайттың өзінен («Кеңейтім» бөлімі) жүктеп алыңыз.

## Кеңейтімді орнату (әдіскерлерге)

1. Сайттағы **Кеңейтім** бөлімінен `juz40-live-extension.zip` жүктеп, ашыңыз.
2. `chrome://extensions` → **Режим разработчика** → **Распакованное расширение** → `manifest.json` тұрған қалта.
3. 1.0.5 / 0.8.3 кеңейтімін өшіріңіз. Ескі кестені көшіру үшін: 1.0.5-те «Резервтік көшірме» → сайтта «Баптаулар → Көшірмені ашу».
4. JUZ40 аккаунтына кіріп, курс бетін ашыңыз, сайтты қайта жүктеп, жоғарыдан сол бетті таңдаңыз.

## Жергілікті іске қосу және тесттер

```bash
npm run dev
```

```bash
npm test
```

`npm test` Playwright мен Chromium-ды қажет етеді. Тест кеңейтімді сайттан жүктелетін zip-тен орнатады, `juz40-edu.kz` мекенжайын жасанды бетпен ауыстырады (нақты сайтқа сұрау жіберілмейді) және мыналарды тексереді: сайт кеңейтімді табады, ашық JUZ40 беті таңдалады, «Бетті тексеру» нәтиже қайтарады, мәтіннен енгізу жұмыс істейді, «Тексеру» жұмыс терезесін ашып, нәтижені сайтқа қайтарады, консольде қате жоқ.

## Әлі тексерілмегені

**API режимі (1.2.0).** Нақты аккаунтта ретімен: (1) режимді «API арқылы»-ға ауыстырып, курс немесе сабақ бетінде «Бетті тексеру» — сессия, курс, топтар, email-дер, «Live сабақ» тегі ✓ болуы керек; (2) «Тексеру» — бет режиміндегі нәтижемен бірдей шығуы керек; (3) тек содан кейін **сынақ сабағында** «Орындау». Бірінші «Орындау»-дан кейін сабақты сайттың өзінде ашып, Meet, дедлайн, нұсқаулықтың жуан қаріпі және тегті көзбен тексеріңіз. Ең алдымен сенімсіз жерлер: `rating-task-types` жауабының пішімі, `POST /v1/lessons` жауабы, жаңа Meet сілтемесінің жауапта бірден келетіні.


Нақты juz40-edu.kz сайтында 1.1.0 әлі сыналған жоқ. Бет құрылымымен жұмыс істейтін код 1.0.5-тегімен бірдей, бірақ жаңа байланыс (сайт → кеңейтім) нақты аккаунтта алдымен **сынақ сабағында** тексерілуі керек: алдымен «Бетті тексеру», сосын «Тексеру» (тек оқиды), тек содан кейін қадағалап отырып «Орындау».
